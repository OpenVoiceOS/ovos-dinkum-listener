# FAQ for ovos-dinkum-listener

### How do I configure the listener?

Configuration is done in `~/.config/mycroft/mycroft.conf` under the `listener` section.

### How do I run the listener?

The listener can be run as a standalone service with the `ovos-dinkum-listener` command.

### How do I test the listener?

Unit tests are in `test/unittests` and can be run with `pytest`.
